# Decision records

One file per non-trivial choice: `NNN-short-title.md`, containing the context, **every option
considered with its trade-offs**, what was chosen, why, and the consequences.

Recording the rejected options is the point. A decision log that lists only what was chosen is a
changelog; the value is in being able to reconstruct *why* an alternative was ruled out, and to
notice when the reason has expired.

Where a choice was made against a real counter-argument, the counter-argument is written down too.

## Numbering

| Range | Area |
|---|---|
| `000–009` | Scope, staging, project-level framing |
| `010–019` | Perception — the vision-language importance layer |
| `020–029` | Coverage control and the decentralized layer |
| `030–039` | Communication model |
| `040–049` | Evaluation harness |
| `050–059` | Experimental design |
| `060–069` | Infrastructure — simulator, bridge, tooling |

Records covering experimental design are kept privately until that work is published; the numbering
above reserves their slots so the public sequence stays stable.
